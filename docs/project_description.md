# Описание программного проекта

## 1. Назначение и границы системы

Система учета транспортных средств организации (вариант 19) предназначена для ведения реестра автопарка, закрепления транспорта за водителями, планирования поездок, учета пробега и контроля технического состояния. Она решает задачу согласованного учета использования служебного транспорта.

В проектируемые границы входят приложение, база данных, конфигурация и журнал событий. Внешние стороны: сотрудники организации, руководство и администратор среды. Кадровая система может быть источником профилей, но интеграция не входит в учебную реализацию. Система не управляет движением транспорта, не подтверждает фактическое местоположение и не заменяет бухгалтерскую или кадровую систему. Для учебных проверок используются искусственные данные.

Текущий код прототипа содержит только загрузку и проверку конфигурации и вывод стартового сообщения. База данных, интерфейс и функции учета не реализованы; их наличие в описании означает проектируемую функциональность. Текущий этап v0.3 расширяет проектную модель угрозами и рисками, но не реализует будущие пользовательские функции.

## 2. Роли

| Роль | Назначение |
|---|---|
| Водитель | Просматривает закрепленные ТС и свои поездки; передает сведения о пробеге и неисправностях. |
| Диспетчер | Ведет карточки ТС, назначает транспорт, планирует поездки, учитывает состояние и обслуживание. |
| Руководитель | Просматривает агрегированные учетные отчеты в рамках служебной задачи; не работает с деталями маршрутов. |
| Администратор | Управляет учетными записями, ролями и настройками; просматривает журнал безопасности. Не получает автоматически доступ ко всем маршрутам и прикладным данным. |
| Неаутентифицированный пользователь | Может обратиться только к форме входа; не получает данные и не выполняет операции. |

Роли и полномочия являются проектной моделью и не реализованы в приложении.

## 3. Основные функции

| ID | Функция | Кто использует | Основные данные | Состояние |
|---|---|---|---|---|
| F-1 | Вход пользователей и проверка учетных данных | Все роли | Идентификатор входа, данные проверки | Запланирована, не реализована |
| F-2 | Просмотр реестра и карточек транспортных средств | Водитель, диспетчер | Госномер, модель, статус, технические сведения | Запланирована, не реализована |
| F-3 | Создание и изменение карточек транспортных средств | Диспетчер | Карточка ТС, статус | Запланирована, не реализована |
| F-4 | Назначение транспорта и планирование поездок | Диспетчер | Водитель, ТС, дата, маршрут | Запланирована, не реализована |
| F-5 | Регистрация поездки, пробега и неисправности | Водитель, диспетчер | Поездка, пробег, результат, дефект | Запланирована, не реализована |
| F-6 | Учет технического состояния и обслуживания | Диспетчер | Статус ТС, дефект, работы, срок ТО | Запланирована, не реализована |
| F-7 | Формирование учетных отчетов | Диспетчер; руководитель читает агрегированные результаты | Сведения об автопарке, поездках, обслуживании | Запланирована, не реализована |
| F-8 | Журналирование значимых действий и событий безопасности | Администратор | Субъект, действие, время, результат | Запланирована, не реализована |
| F-9 | Загрузка и проверка конфигурации при старте | Администратор среды при локальном запуске | APP_NAME, APP_ENV, APP_SECRET_KEY | Реализована в `app/config.py` |
| F-10 | Формирование стартового сообщения без вывода секрета | Запускающий приложение пользователь | Название приложения, режим работы | Реализована в `app/main.py` |
