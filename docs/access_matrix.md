# Предварительная матрица доступа

Матрица задает планируемые полномочия, но не реализована в приложении. Роли не наследуют права друг друга. По умолчанию любое явно не разрешенное действие запрещено. Администратор управляет учетными записями и безопасностью, но не получает автоматического доступа к маршрутам и содержимому всех поездок. Руководителю доступна только сводная отчетность.

| Операция | Неаутентифицированный пользователь | Водитель | Диспетчер | Руководитель | Администратор |
|---|---|---|---|---|---|
| Обращение к форме входа | Разрешено, без выдачи данных | Разрешено | Разрешено | Разрешено | Разрешено |
| Просмотр карточки ТС | Запрещено | Только закрепленное ТС | Весь автопарк по служебной задаче | Запрещено | Запрещено по умолчанию; доступ только к полям, нужным для управления учетными записями |
| Создание/изменение карточки ТС | Запрещено | Запрещено | Разрешено | Запрещено | Запрещено |
| Просмотр поездки и маршрута | Запрещено | Только собственная назначенная поездка | По поездкам автопарка в рамках диспетчерской работы | Запрещено | Запрещено по умолчанию |
| Создание/изменение назначения и плана поездки | Запрещено | Запрещено | Разрешено | Запрещено | Запрещено |
| Передача результата поездки/неисправности | Запрещено | Только по собственной назначенной поездке | В рамках учета автопарка | Запрещено | Запрещено |
| Изменение данных обслуживания | Запрещено | Запрещено; допускается передача сообщения о дефекте | Разрешено | Запрещено | Запрещено |
| Просмотр учетного отчета | Запрещено | Запрещено | Разрешено по служебной задаче | Только агрегированный отчет | Запрещено по умолчанию |
| Управление учетными записями и ролями | Запрещено | Запрещено | Запрещено | Запрещено | Разрешено по установленной процедуре |
| Просмотр журнала безопасности | Запрещено | Запрещено | Запрещено | Запрещено | Разрешено в рамках обязанностей безопасности |

Проверка принадлежности данных обязательна: для водителя сверяется назначение конкретной поездки и транспортного средства. Доступ руководства к агрегированным отчетам не раскрывает исходные маршруты и детали поездок. Для учебной модели совмещение нескольких ролей не предполагается; если потребуется, полномочия будут описаны явно.
