# Система учета транспортных средств организации

## Назначение

Система учета транспортных средств организации - учебный программный проект для учета и управления транспортными средствами организации. Проект разрабатывается по дисциплине «Основы разработки защищенного программного обеспечения и компьютерных сетей».

## Индивидуальный вариант

Вариант 19 - система учета транспортных средств организации.

## Основные роли пользователей

- Водитель - просматривает закрепленные транспортные средства и передает сведения о поездках.
- Диспетчер - ведет учет транспортных средств, назначает их водителям и контролирует состояние.
- Администратор - управляет учетными записями, ролями, настройками системы и событиями безопасности.

## Используемые технологии

- Python 3.11 or newer;
- Git;
- python-dotenv;
- pytest.

## Структура проекта

- `app/` - исходный код приложения;
- `tests/` - автоматические тесты;
- `docs/` - документация проекта;
- `.env.example` - безопасный шаблон конфигурации;
- `.gitignore` - правила исключения конфиденциальных и служебных файлов;
- `requirements.txt` - зафиксированные зависимости проекта.

## Запуск проекта

1. Создать и активировать виртуальное окружение: `python3 -m venv .venv` и `source .venv/bin/activate`.
2. Установить зависимости: `python -m pip install -r requirements.txt`.
3. Скопировать `.env.example` в `.env` и заменить `APP_SECRET_KEY` случайным значением длиной не менее 32 символов.
4. Выполнить запуск: `python -m app.main`.

## Тестирование

Выполнить команду `python -m pytest -v`.

## Требования безопасности

- Секреты не хранятся в исходном коде и не добавляются в Git.
- Конфигурация загружается из переменных окружения и проверяется при запуске.
- Секретный ключ должен содержать не менее 32 символов.
- Секретные значения не выводятся в консоль.
- Зависимости зафиксированы в `requirements.txt`.
